 Store Sales Data Analysis & Insights

An Exploratory Data Analysis (EDA) and visualization project analyzing store sales performance, customer demographics, product categories, and temporal sales trends using Python.

---

## 📌 Project Overview

This project analyzes retail performance using the `store_sales.csv` dataset sourced from [Kaggle](https://www.kaggle.com/datasets/hassanjameelahmed/store-sales). The analysis covers key metrics such as sales growth over time, customer demographics, top-performing product categories, correlation analysis, and strategic business recommendations.

---

## 🛠️ Tech Stack & Tools

- **Language:** Python
- **Data Manipulation:** `pandas`, `numpy`
- **Data Visualization:** `matplotlib`, `seaborn`
- **Environment:** Jupyter Notebook / VS Code
